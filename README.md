# 🛒 E-Commerce Website

A modern, fully responsive **E-Commerce Website** built using **HTML5, CSS3, and JavaScript**. This project provides a clean online shopping interface with multiple pages, responsive design, product showcases, promotional banners, and a shopping cart layout. It demonstrates core frontend web development skills and user-friendly website design.

---

## 📌 Project Overview

The E-Commerce Website is a static frontend shopping application designed to simulate a real online retail platform. It includes dedicated pages for products, product details, cart, blog, about, and contact information while maintaining a consistent and responsive user interface across desktop, tablet, and mobile devices.

This project focuses on building reusable UI components, responsive layouts, and interactive navigation using JavaScript.

---

## ✨ Features

- 🏠 Responsive Home Page with hero banners and featured collections.
- 🛍️ Shop Page displaying products in a clean grid layout.
- 📦 Single Product Page with detailed product information.
- 🛒 Shopping Cart interface for selected products.
- 📖 Blog section showcasing promotional articles.
- ℹ️ About page describing the brand and services.
- 📞 Contact page with location and contact information.
- 📱 Mobile-friendly navigation menu.
- 🎨 Modern UI with reusable product cards and banners.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Sumanth0804/Ecommerce-website.git
```

### Run the Project

1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (recommended).
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website will launch in your browser.
